# Component: Managed Kubernetes cluster

**Terraform resource:** `nebius_mk8s_v1_cluster.primary`
**Nebius service:** Managed Service for Kubernetes (MK8s)

## What it is

A Kubernetes control plane run and patched by Nebius, plus the worker node groups you attach to it. You manage the nodes; Nebius manages the control plane.

## Why it is here

It runs everything in this system: the ingest jobs, the training job, the vLLM inference server, the RAG API, and the monitoring stack. A managed control plane avoids running etcd and the API server yourself, which is the part most likely to take up engineering time.

## Key settings

| Argument | Value in this repo | Reason |
|---|---|---|
| `control_plane.version` | `var.k8s_version` (default `1.32`) | Check supported versions with `nebius mk8s cluster list-control-plane-versions`. |
| `control_plane.subnet_id` | `var.subnet_id` | Nodes and the control plane share this subnet. |
| `control_plane.etcd_cluster_size` | `1` (budget), `3` (production) | Fewer members cost less but offer no fault tolerance. The validation allows only 1 or 3. |
| `control_plane.endpoints.public_endpoint.allowed_cidrs` | `var.admin_cidrs` | Limits who can reach the API. A validation blocks `0.0.0.0/0`. |

## Access

The kubeconfig is not a Terraform output because it is generated by the CLI:

```bash
nebius mk8s cluster get-credentials --id <cluster-id> --external --kubeconfig ~/.kube/spiritual-rag.yaml
```

Use `--internal` only from a VM in the same subnet. Without a public endpoint, the cluster is reachable only from that subnet.

## Operations

- **Upgrades:** change `k8s_version` and apply. Node groups roll over to the new version on their own schedule.
- **Cost:** the managed control plane has no per-hour node charge in the reference material, but check the current price list. Worker nodes are billed while they run.
- **Failure modes:** if `allowed_cidrs` does not include your current IP, `kubectl` times out. Update the list and re-apply. Your home IP may change, so keep the list short.
